# 大学生竞赛活动管理平台 - 前端

## 技术栈
- Vue 3
- Vue Router 4
- Pinia
- Element Plus
- Axios
- Vite

## 项目结构
```
Competition-vue/
├── src/
│   ├── api/           # API接口
│   ├── assets/       # 静态资源
│   ├── components/    # 组件
│   ├── layouts/       # 布局
│   ├── router/        # 路由
│   ├── stores/        # 状态管理
│   ├── utils/         # 工具类
│   └── views/         # 页面
│       ├── admin/     # 管理员页面
│       ├── student/   # 学生页面
│       └── teacher/   # 老师页面
└── package.json
```

## 启动步骤

1. 安装依赖
```bash
npm install
```

2. 启动开发服务器
```bash
npm run dev
```

3. 访问 http://localhost:3000

## 默认账号
- 管理员：admin / admin123
- 学生：需要注册
- 老师：需要管理员创建
